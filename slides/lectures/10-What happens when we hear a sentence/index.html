How many possible sentences were there?

If we just randomly combine words (and treat reshufflings of words as equivalent), you could have 8,568 different sentences!

  • It would include real sentences, like:
    • the dog chased a cat
    • a squirrel ate some acorns
  • But it would include slightly wrong sentences, like:
    • *an cat scratched the tree
    • *each apple ate the dog
  • And some very wrong sentences, like:
    • *chased cat dog buried the
    • *acorns dog squirrel tree cat

\[ Pk = \frac{n!}{(n -k)!} = \frac{18!}{(13 - 5)!} \]

And it misses some real sentences!

Randomly combining words and treating reshufflings as equivalent has two other problems:

  • It would miss real sentences like ones you might have created:
    • the dog chased the cat
    • some squirrel ate some acorns
  • Maybe more importantly, it makes a huge error and treats these as the same sentence:
    • the dog sniffed the cat
    • the cat sniffed the dog

Permutations: words can repeat and order matters?

So let’s say repetitions are allowed and we care about the order words appear in. Now how many?

1,889,568

= \(n^k\) possible sentences

This actually fixes some problems!

  • Now we can account for sentences like:
    • the dog chased the cat
    • a cat blocked the cat
    • the dog chased the cat != the cat chased the dog
    • and many others!

But it creates new garbage and keeps old garbage

  • *chased cat dog buried the
  • *an squirrel apple cat acorns
  • *an the each every some
  • *cat cat cat cat cat

Syntax

With just those restrictions, the number of possible sentences drops to 7,776

  • This gets ride of most of the ungrammatical sentences, but it leaves us with things like:
  • *the dog ate a apple
  • *each squirrel buried a acorns
  • *an cat scratched an tree

How do we fix this?

Morphology

If we add a morphological rule that an can only come before words that start with a vowel (apple, acorns) the number of sentences drops to 5,400 and now includes mostly sentences we want it to! Sample sentences look like:

  • the squirrel sniffed an apple
  • each squirrel climbed the dog
  • every squirrel climbed each tree
  • *the squirrel sniffed each acorns
  • *the squirrel sniffed every acorns

What’s wrong?

Morphology

A thing you just know about English without ever having been explicitly told is that the, a, an, each, and every are singular! They can’t be paired with a plural noun like acorns.

  • If we add a pair of morphological rules that say this, the number of possible sentences drops to 4,056!
  • And it’s really starting to look like English!
    • every cat climbed a tree
    • some cat buried the apple
    • a tree blocked the squirrel
    • the squirrel sniffed the apple
    • each dog chased some acorns

Morphology?

  • But we still get sentences like:
    • *some acorns ate some squirrel
    • *each apple chased each apple
    • *an apple climbed a tree
  • What’s wrong with these?

Semantics!

A thing you just know about English, without ever having been explicitly told, is that verbs like the ones in Column C have to be done by living things (or non-living things with living-like abilities e.g. robots)

  • We need semantic rules something like:
    • Only animate things can climb, chase, bury, sniff, or scratch
    • Which means that one of the things you know when you know a word is whether that words is animate or inanimate
    • If we add these rules, now the number of possible sentences drops to 2,626 (down from 1,889,568)

Okay, so what happens when we hear a sentence?

How we hear a sentence

  • Vibrations arrive at our ears and get converted into electrochemical signals to our brains
  • Our brains use these signals to search our mental lexicons for words
  • Our brains make guesses as the signal unfolds
  • If we make a mistake we back up!

How sentences work

  • Speech is a sequence of sounds, that our brains turn into words
  • Sentences are sequences of words, arranged hierarchically, with morphological, syntactic, and semantic dependencies binding the words together and helping talkers and listeners create meaning
  • (Looking ahead, we also use social information about the talker to understand speech!)
  • Sentences are not created by randomly stringing words together
  • in our play example, only 0.0013% combinations of the possible sentences formed from the 18 words were actually grammatical in the linguistic sense

How we hear a sentence

  • Hearing (and understanding) a sentence involves many, interlocking layers of knowledge, inference, and educated guessing
  • We use layers of information to predict and understand what others are saying!
  • One of the ways linguists know for certain that slang, swearing, dialects, and violations of prescriptive rules are valid is that we process these things in the same way!
  • As listeners, we use our knowledge of sounds, morphemes, syntax, semantics, and pragmatics to create our private, interal representation of what the talker must have meant
